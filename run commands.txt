## Medora — Run Commands

### Frontend Setup (from scratch)

# 1. Create Vite + React project
npm create vite@latest frontend -- --template react

# 2. Navigate into frontend
cd frontend

# 3. Install TailwindCSS
npm install -D tailwindcss postcss autoprefixer
npx tailwindcss init -p

# 4. Install all required packages
npm install react-router-dom react-icons react-spinners react-toastify swiper jspdf html2canvas

# 5. Create .env file in frontend/ and add:
VITE_HEALTH_PREDICT_API_KEY=your_groq_key_1
VITE_FIND_DOCTOR_API_KEY=your_groq_key_2
VITE_GROQ_API_URL=https://api.groq.com/openai/v1/chat/completions
VITE_GROQ_MODEL=llama-3.3-70b-versatile

# 6. Start development server
npm run dev

# 7. Build for production
npm run build


### Git Commands

# Clone the repository
git clone https://github.com/Apurvk28/medora.git

git add .

# Commit
git commit -m "your message here"
